# Embroidery ERP Lite

Simple web app for a small embroidery factory (around 50 workers) with:

- Design number tracking
- Stitches count tracking
- Design picture URL
- Worker attendance marking

## Run

```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000`

## Notes

- Data is stored in browser localStorage
- No backend/database required for this starter version
